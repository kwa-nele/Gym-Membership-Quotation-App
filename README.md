# Gym-Membership-Student-Quotation-App
C++ gym membership quotation app


This C++ console application generates a membership quotation for student gym memberships. The program captures the student's number and full name, displays the three membership options (Basic Access R220, Active Plus R350, Complete Wellness R480), and asks for the membership code, the number of months (1 to 6) and whether the optional once-off fitness assessment (R180) is required. All input is validated, and if anything is invalid the program shows a meaningful error message and stops without producing a quotation. For valid input, it determines the monthly fee using an if / else if structure, applies a 7% commitment discount for 3 to 5 months or a 12% discount for exactly 6 months, and calculates the subtotal, discount and final amount. A detailed quotation showing all intermediate values is then displayed. To run it, compile with `g++ vukafit_quotation_final.cpp -o vukafit` and run `./vukafit`. For example, entering VF1008, Naledi Mokoena, Complete Wellness, 6 months and the assessment gives a final amount of R2714.40.
